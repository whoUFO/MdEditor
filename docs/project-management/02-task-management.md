**详细步骤**：

1. 创建 pnpm-workspace.yaml
   ```yaml
   packages:
     - 'apps/*'
     - 'packages/*'
   ```

2. 配置 turbo.json
   ```json
   {
     "pipeline": {
       "build": { "dependsOn": ["^build"] },
       "dev": { "cache": false, "persistent": true }
     }
   }
   ```

3. 根 package.json scripts
   ```json
   {
     "scripts": {
       "dev": "turbo dev",
       "build": "turbo build",
       "lint": "turbo lint",
       "test": "turbo test"
     }
   }
   ```
