## 1. 产品概述

### 1.1 产品定位

Electron Markdown Editor 是一款面向开发者和技术写作者的现代化 Markdown 桌面编辑器。产品定位为**专业级 Markdown 编辑工具**，提供所见即所得的编辑体验、强大的文件管理能力和丰富的富文本渲染功能。

### 1.2 核心价值主张

- **高效编辑**：双栏实时预览 + 智能防抖，让写作更流畅
- **专业渲染**：支持数学公式、流程图、代码高亮等专业内容
- **本地优先**：直接操作本地文件系统，无需云端依赖
- **安全可靠**：多层安全防护，保护用户数据安全

### 1.3 目标用户

| 用户类型 | 特征 | 核心需求 |
|---------|------|---------|
| 技术写作者 | 撰写技术文档、博客 | 代码高亮、数学公式、导出功能 |
| 开发者 | 编写 README、API 文档 | 文件管理、Git 集成、快捷键 |
| 学生/研究人员 | 写论文、笔记 | 公式支持、目录导航、PDF 导出 |
| 产品经理 | 编写需求文档 | 图表支持、协作分享 |

## 2. 功能需求

### 2.1 核心编辑功能

#### 2.1.1 双栏编辑界面

**需求描述**：
- 左侧为 Markdown 编辑区，右侧为实时预览区
- 支持调整分栏比例（可拖动分割线）
- 支持单栏模式切换（仅编辑或仅预览）

**验收标准**：
- [ ] 分栏比例可在 20:80 到 80:20 之间调整
- [ ] 分割线拖动流畅，无卡顿
- [ ] 单栏模式切换响应时间 < 100ms

#### 2.1.2 实时预览渲染

**需求描述**：
- 编辑区内容变化后 300ms 自动触发预览更新
- 预览区滚动位置保持相对一致
- 支持手动刷新预览

**验收标准**：
- [ ] 防抖延迟准确为 300ms
- [ ] 大文档（>10000 字）渲染时间 < 500ms
- [ ] 滚动同步误差 < 50px

#### 2.1.3 预览面板开关

**需求描述**：
- 支持通过工具栏按钮或快捷键打开/关闭预览面板
- 预览面板关闭后，编辑区自动扩展占满整个窗口
- 预览面板打开时，恢复之前的分栏布局
- 预览面板状态（打开/关闭）持久化保存
- 支持快捷键 Ctrl+Shift+P 快速切换预览面板

**验收标准**：
- [ ] 预览面板切换响应时间 < 100ms
- [ ] 切换时编辑区内容不丢失
- [ ] 预览面板状态在应用重启后保持
- [ ] 快捷键 Ctrl+Shift+P 正常工作
- [ ] 工具栏按钮显示当前预览状态（打开/关闭图标）

#### 2.1.4 编辑器基础功能

**需求描述**：
- 基于 CodeMirror 6 的文本编辑器
- 支持语法高亮（Markdown 语法）
- 支持代码折叠
- 支持行号显示（可开关）
- 支持自动缩进
- 支持括号匹配

**验收标准**：
- [ ] Markdown 语法高亮准确识别标题、列表、代码块等
- [ ] 代码块内支持对应语言的语法高亮
- [ ] 行号显示/隐藏切换即时生效

### 2.2 文件管理功能

#### 2.2.1 文件打开

**需求描述**：
- 支持通过菜单或快捷键打开文件对话框
- 支持拖拽文件到编辑器打开
- 支持最近打开文件列表（最近 10 个）
- 自动检测文件编码（UTF-8、GBK、Shift-JIS 等）

**验收标准**：
- [ ] 文件对话框支持 .md、.markdown、.txt 等扩展名过滤
- [ ] 拖拽文件打开响应时间 < 500ms
- [ ] 最近文件列表持久化保存
- [ ] 编码检测准确率 > 95%

#### 2.2.2 文件保存

**需求描述**：
- 支持 Ctrl+S 快捷键保存
- 支持"另存为"功能
- 支持自动保存（可选，默认关闭）
- 保存时保留原文件编码

**验收标准**：
- [ ] 保存快捷键响应时间 < 100ms
- [ ] 自动保存间隔可配置（默认 30 秒）
- [ ] 保存前提示未保存的修改
- [ ] 编码一致性保持 100%

#### 2.2.3 目录树浏览

**需求描述**：
- 左侧边栏显示文件目录树
- 支持展开/折叠文件夹
- 点击文件在编辑器中打开
- 支持文件搜索过滤

**验收标准**：
- [ ] 目录树加载 1000 个文件无卡顿
- [ ] 文件夹展开/折叠动画流畅
- [ ] 文件搜索支持实时过滤
- [ ] 当前打开文件高亮显示

**已知缺口**：文件树右键菜单（新建/重命名/删除）将在下一迭代实现

### 2.3 工具栏与快捷键

#### 2.3.1 工具栏功能

**需求描述**：
- 顶部工具栏提供常用格式按钮
- 按钮分组：文本格式、插入元素、编辑操作
- 鼠标悬停显示功能提示和快捷键

**工具栏按钮清单**：

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 预览开关 | 打开/关闭预览面板 | Ctrl+Shift+P |
| 加粗 | 插入 **粗体** | Ctrl+B |
| 斜体 | 插入 *斜体* | Ctrl+I |
| 删除线 | 插入 ~~删除线~~ | Ctrl+Shift+S |
| 标题1-6 | 插入 # 标题 | Ctrl+1~6 |
| 无序列表 | 插入 - 列表项 | Ctrl+Shift+U |
| 有序列表 | 插入 1. 列表项 | Ctrl+Shift+O |
| 引用块 | 插入 > 引用 | Ctrl+Shift+] |
| 代码块 | 插入 ``` 代码块 | Ctrl+Shift+K |
| 行内代码 | 插入 `代码` | Ctrl+K |
| 链接 | 插入 [链接](url) | Ctrl+L |
| 图片 | 插入 ![alt](src) | Ctrl+Shift+I |
| 分割线 | 插入 --- | Ctrl+Shift+H |
| 表格 | 插入表格模板 | Ctrl+Shift+T |
| 撤销 | 撤销操作 | Ctrl+Z |
| 重做 | 重做操作 | Ctrl+Y / Ctrl+Shift+Z |

#### 2.3.2 快捷键系统

**需求描述**：
- 支持 18+ 个快捷键
- 快捷键可自定义（后续版本）
- 快捷键提示显示在工具栏按钮上

**验收标准**：
- [ ] 所有快捷键响应时间 < 50ms
- [ ] 快捷键与系统快捷键无冲突
- [ ] 快捷键提示显示准确

### 2.4 富文本渲染

#### 2.4.1 数学公式渲染

**需求描述**：
- 支持行内公式：$E=mc^2$
- 支持块级公式：$$公式$$
- 使用 KaTeX 引擎渲染
- 支持常见数学符号和公式

**验收标准**：
- [ ] 行内公式渲染正确
- [ ] 块级公式居中显示
- [ ] 复杂公式（矩阵、积分）渲染正确
- [ ] 公式渲染时间 < 200ms

#### 2.4.2 图表渲染

**需求描述**：
- 支持 Mermaid 语法
- 支持流程图、时序图、甘特图、类图
- 图表可缩放和导出

**验收标准**：
- [ ] 流程图渲染正确
- [ ] 时序图渲染正确
- [ ] 图表支持 SVG 格式导出
- [ ] 图表渲染时间 < 500ms

#### 2.4.3 代码高亮

**需求描述**：
- 使用 highlight.js 进行代码高亮
- 支持 10+ 种编程语言
- 支持行号显示
- 支持代码复制按钮

**支持语言清单**：
- JavaScript / TypeScript
- Python
- Java
- C / C++
- Go
- Rust
- HTML / CSS
- JSON / YAML
- SQL
- Shell / Bash

**验收标准**：
- [ ] 代码块语法高亮准确
- [ ] 行号对齐正确
- [ ] 复制按钮功能正常
- [ ] 支持的语言识别率 100%

### 2.5 导航与同步

#### 2.5.1 自动目录生成

**需求描述**：
- 右侧边栏显示文档目录树
- 根据标题层级自动构建目录
- 点击目录项跳转到对应位置
- 当前位置高亮显示

**验收标准**：
- [ ] 目录层级识别准确（H1-H6）
- [ ] 点击跳转定位准确
- [ ] 滚动时高亮同步更新
- [ ] 目录更新响应时间 < 100ms

#### 2.5.2 滚动同步

**需求描述**：
- 编辑区滚动时预览区同步滚动
- 预览区滚动时编辑区同步滚动
- 支持双向同步开关

**验收标准**：
- [ ] 滚动同步延迟 < 50ms
- [ ] 同步定位误差 < 50px
- [ ] 大文档同步无卡顿

### 2.6 主题系统

#### 2.6.1 主题切换

**需求描述**：
- 支持明亮主题和暗黑主题
- 主题切换即时生效
- 主题偏好持久化保存

**验收标准**：
- [ ] 主题切换时间 < 100ms
- [ ] 所有组件主题一致
- [ ] 主题偏好重启后保持

#### 2.6.2 主题定制

**需求描述**：
- 使用 CSS 变量驱动主题
- 支持自定义主题颜色（后续版本）

**验收标准**：
- [ ] CSS 变量定义完整
- [ ] 主题切换无闪烁

### 2.7 导出功能

#### 2.7.1 HTML 导出

**需求描述**：
- 导出为独立 HTML 文件
- 包含内联样式
- 保留数学公式、图表渲染效果

**验收标准**：
- [ ] 导出文件可离线查看
- [ ] 样式与预览一致
- [ ] 导出时间 < 2s

#### 2.7.2 PDF 导出

**需求描述**：
- 导出为 PDF 文件
- 支持页面设置（边距、方向）
- 保留完整格式

**验收标准**：
- [ ] PDF 渲染正确
- [ ] 支持 A4 页面设置
- [ ] 导出时间 < 5s

### 2.8 安全功能

#### 2.8.1 内容安全

**需求描述**：
- 内容安全策略（CSP）限制
- Markdown 渲染使用 rehype-sanitize 净化
- DOMPurify 二次净化
- 禁用危险 HTML 标签

**验收标准**：
- [ ] XSS 攻击防护有效
- [ ] 危险标签被正确过滤
- [ ] 正常内容渲染不受影响

#### 2.8.2 进程安全

**需求描述**：
- 启用 contextIsolation
- 启用 sandbox
- 禁用 nodeIntegration
- 使用 contextBridge 安全暴露 API

**验收标准**：
- [ ] 渲染进程无法直接访问 Node.js API
- [ ] IPC 通信安全可控
- [ ] 通过安全审查

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 目标值 | 测试场景 |
|------|--------|---------|
| 启动时间 | < 3s | 冷启动 |
| 文件打开 | < 500ms | 1MB 文件 |
| 预览渲染 | < 500ms | 10000 字文档 |
| 内存占用 | < 500MB | 正常使用 |
| 响应延迟 | < 50ms | 快捷键操作 |

### 3.2 兼容性需求

- **操作系统**：Windows 10+ / macOS 10.15+ / Ubuntu 20.04+
- **Electron 版本**：41.x
- **Node.js 版本**：20.x LTS

### 3.3 可靠性需求

- 自动保存防止数据丢失
- 崩溃恢复机制
- 文件备份机制（可选）

### 3.4 可维护性需求

- 代码覆盖率 > 80%
- 类型检查严格模式
- 代码规范 ESLint + Prettier

## 4. 用户界面需求

### 4.1 界面布局

```
┌─────────────────────────────────────────────────────────────┐
│  菜单栏                                                      │
├─────────────────────────────────────────────────────────────┤
│  工具栏                                                      │
├──────────┬──────────────────────────┬───────────────────────┤
│          │                          │                       │
│  目录树   │      编辑区               │      预览区           │
│  侧边栏   │                          │                       │
│          │                          │                       │
│          │                          │                       │

### 4.2 界面元素

- **菜单栏**：文件、编辑、视图、帮助

- **预览区**：渲染内容、滚动条
